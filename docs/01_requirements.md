# Требования к программе учета и анализа личных финансов

## Назначение
Программа помогает одному пользователю вести учет личных доходов и расходов и анализировать структуру расходов.

## Функциональные требования
1. Добавление дохода с указанием категории, суммы и комментария.
2. Добавление расхода с указанием категории, суммы и комментария.
3. Просмотр списка всех операций.
4. Расчет общей суммы доходов, расходов и остатка.
5. Отчет по категориям расходов за выбранный месяц с долей каждой категории в процентах.
6. Сохранение данных между запусками программы.

## Нефункциональные требования
1. Язык реализации: Python 3.12 или новее.
2. Интерфейс: консольное меню на русском языке.
3. Хранение данных: файл transactions.csv в кодировке UTF-8.
4. Программа проверяет ввод и не принимает отрицательную или нулевую сумму.
