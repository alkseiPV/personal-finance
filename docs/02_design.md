# Проектные решения

## Модули
- finance.py: хранение операций и расчеты.
- main.py: консольное меню и диалог с пользователем.
- test_finance.py: модульные тесты.

## Структура данных
Файл transactions.csv, одна строка соответствует одной операции.

| Поле | Описание | Пример |
|---|---|---|
| date | дата операции в формате ГГГГ-ММ-ДД | 2026-11-12 |
| type | доход или расход | расход |
| category | категория | Продукты |
| amount | сумма в рублях | 4500.50 |
| comment | комментарий | Магазин у дома |

## Пункты меню
1. Добавить доход
2. Добавить расход
3. Показать все операции
4. Показать баланс
5. Отчет по категориям расходов за месяц
0. Выход
