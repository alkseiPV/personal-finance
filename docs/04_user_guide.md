# Руководство пользователя

1. Установите Python 3.12 или новее.
2. Скачайте репозиторий кнопкой Code, затем Download ZIP, или командой git clone.
3. Откройте папку проекта в терминале и выполните команду python main.py.
4. Выберите пункт меню цифрой и нажмите Enter.
5. Данные сохраняются в файл transactions.csv рядом с программой.
