# Программа учета и анализа личных финансов

Учебный проект по дисциплине «Проектная деятельность в ИТ».
Автор: Плотников Алексей Васильевич.

Программа ведет учет доходов и расходов и строит отчет о структуре расходов по категориям.

## Запуск
python main.py

## Структура репозитория

- docs: документы стадий жизненного цикла
- finance.py: расчеты
- main.py: меню программы
